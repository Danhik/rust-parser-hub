# Parser Hub 🚀

**Parser Hub** — это современная веб-панель управления (контрольная панель) для запуска и мониторинга парсеров цен и инвентарей популярных торговых площадок (Steam, Tradeit.gg, Swap.gg, Skinswap.com). 

Проект полностью автономен, находится внутри папки `parser_hub` и не требует настройки внешних путей.

---

## ✨ Основные возможности

1. **Красивый Web-интерфейс**: Современный темный дизайн в стиле Glassmorphism (эффект матового стекла), динамические графики статуса задач, автопрокрутка логов.
2. **Многозадачность и Логирование**: Запуск нескольких парсеров одновременно, отслеживание логов выполнения в реальном времени, возможность принудительной остановки (`taskkill`).
3. **Автоматическое сканирование окружения**:
   - 🔑 **SDA-профили**: автоматически считывает файлы аккаунтов `.maFile` из папки `sda_profiles/`.
   - 👥 **Chrome-профили**: сканирует и позволяет создавать/удалять профили браузера прямо из интерфейса для работы Selenium.
   - 🌐 **Прокси**: автоматически подгружает списки прокси `.txt` из папки `parsers/`.
   - 🔓 **Сессии**: находит файлы сохраненных куков авторизации (`tradeit_session_*.json`, `skinswap_session_*.json`).
4. **Построитель связок (Links Builder)**: Сравнение полученных прайс-листов, вычисление чистой прибыли с учетом комиссий и ROI (%), экспорт результатов в Excel.

---

## 🛠️ Структура проекта

* `app.py` — Flask-сервер (бэкэнд бэкапа и API панели).
* `static/` — Фронтенд (HTML, CSS, JS, иконки).
* `data/` — Директория для выходных Excel-таблиц (`.xlsx`).
* `chrome_profiles/` — Директория для профилей Chrome/Selenium.
* `sda_profiles/` — Директория для файлов автоподтверждения `.maFile` (Steam Desktop Authenticator).
* `parsers/` — Скрипты самих парсеров, файлы прокси (`proxies.txt`) и списки имен (`names.txt`).

## 📥 Установка и запуск

### 1. Установка зависимостей
Убедитесь, что у вас установлен Python 3.8 или новее.
```bash
pip install -r requirements.txt
```

Для работы браузерных парсеров (Selenium/Playwright) инициализируйте бинарные файлы браузеров:
```bash
playwright install
```

### 2. Запуск панели
```bash
python app.py
```
После запуска откройте браузер по адресу: **[http://localhost:5050](http://localhost:5050)**

## 💡 Особенности запуска парсеров

### Парсинг Steam (без прокси)
Steam очень быстро блокирует IP-адреса за частые запросы (ошибка `429 Too Many Requests`). 
* Если у вас **нет рабочих прокси**, выберите в веб-панели прокси: **`— без прокси —`**.
* Включите ваш **VPN** на компьютере.
* Установите **Потоки: 1**, а **Интервал задержки: 3.0** или **4.0** секунды.
* Если Steam временно ограничит доступ (пойдут `fail`), просто смените страну/сервер в вашем VPN-клиенте и перезапустите скрипт. Благодаря функции **Resume Support** скрипт автоматически продолжит работу и не будет скачивать повторно уже собранные предметы.

## 📝 Размещение файлов

* **Прокси**: Положите файлы формата `ip:port:user:pass` (один прокси на строку) в папку `parser_hub/parsers/` с расширением `.txt` (например, `proxies.txt`).
* **SDA файлы**: Переместите ваши `.maFile` в папку `parser_hub/sda_profiles/`. Панель считает их автоматически.
